# sinapse-brand

Fonte-da-verdade única, viva e navegável da marca SINAPSE.

- **Brandbook** — estratégia, manifesto, arquétipo, voz, jornada
- **Design System** — tokens, componentes, motion, patterns, templates
- **Showcase** — editorial · prova de uso real

## Stack

Next.js 15 · React 19 · TypeScript · Tailwind · shadcn/ui · MDX · Style Dictionary · Fraunces + Geist + Geist Mono

## Dev

```bash
npm install
npm run dev
```
