# overlay.com — crawl

**Stack:** Webflow.
**Fontes:** `PP Editorial Old` (serif elegante para H1/H2) + `Roboto Flex` (body) + `Geist Mono` (300/400/500). **3-axis: serif display + sans body + mono accent.**
**Tema:** Bg `#FBF9FB` (off-white quente quase branco) + text `#2E2F53` (navy quase preto).
**H1 == H2:** ambos PP Editorial 72px / 400 — display unificado.
**Media:** has_video + has_canvas + 14 SVGs + AVIF detectado ✅. Confirma "AVIF gradients".
**Sections:** 5. **Scroll:** 8360px.

## Sinal pro SINAPSE
**MÉDIO-ALTO** — diferente do nosso DNA (serif + cor warm), mas ricos aprendizados técnicos.

**Absorvíveis:**
1. **PP Editorial Old serif** = "tech sofisticado" — robotics company usar serif clássico cria contraste único. Para SINAPSE não combina (manter sans), mas guardar pra brand secundária.
2. **Geist Mono em 3 pesos (300/400/500)** — exatamente o range mono que SINAPSE precisa. **Substituir JetBrains Mono por Geist Mono** seria upgrade claro.
3. **AVIF format** confirmado em produção — formato 50% menor que WebP. **Adicionar AVIF como primary image format no SINAPSE**.
4. **Bg `#FBF9FB`** — quase branco com leve tinge magenta — confirma que "off-white é melhor que branco puro". Nosso Bone `#F5F5F0` (warm) está alinhado.
5. **14 SVGs** — frames decorativos via SVG inline (já no plano `.frame-tech`).
6. **H1 == H2 size** — quando display único, força hierarquia por contexto não por escala. Considerar pra brandbook.
