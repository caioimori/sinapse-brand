# stripe.com/br — crawl

**Stack:** custom (não framework standard). HTML semântico extremo (15 sections).
**Fontes:** `sohne-var` (variable, weight 1-1000) + `SourceCodePro 500` para code blocks. Stripe pagou pra ter sohne exclusiva — assinatura tipográfica forte.
**Tema:** Light (bg transparente cascateia pra branco), text preto puro `#000`.
**H1:** sohne 44px / **300 (Light!)** / lh 50.6px — display delgado, oposto do bold heavy convencional.
**H2:** 32px sohne. Hierarquia tipográfica restrita (44 → 32 → 24).
**Canvas:** SIM — gradient hero animado (a famosa "Stripe wave").
**Marquee:** SIM. **Sections:** 15. **Scroll:** 14976px (longuíssima).

## Sinal pro SINAPSE
**ALTO.** Stripe é o paradigma de "minimal corporate enterprise" + "tipografia como assinatura". Lições:

**Absorvíveis:**
- **H1 weight 300** (Light) em 44px — nosso Sora atual está no Bold/SemiBold. Considerar variante weight light para hero principais
- **Tipografia variable** (sohne-var weight 1-1000) — nossa Sora também é variable, podemos explorar weight micro-axes (400-450-500) ao invés do tradicional 400/700
- **Hero canvas com gradient animado** (Stripe wave) — fora do nosso escopo B&W mas técnica vale: WebGL gradient sutil em background = signature visual
- **Bento grid** + cards lockup com fotografia conceitual (carrosséis de produtos)
- **Pricing tier carousel infinito** com logos de clientes
- **Page super-longa** (15 sections, 14976px) — aceitar comprimento, dividir em narrativa
