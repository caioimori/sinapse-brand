## Sinal pro SINAPSE
**MÁXIMO — referência DNA #2.** Tom AI/automação aspiracional alinhado com SINAPSE.

**Absorvíveis CRÍTICOS:**
1. **`//` prefix em todo eyebrow/section label** — não é decoração, é sistema. Aplicar em meta labels SINAPSE (`//FOUNDATIONS`, `//MOTION`, `//TOKEN EXPORT`).
2. **H2 como eyebrow MONO minúsculo (~14px)** — não como "subtítulo grande". Inverter hierarquia: H1 grande, H2 micro-label.
3. **Hora local + data ao vivo** no footer/header — vira "presença" do site, técnica trivial JS. **JÁ no plano FASE A** ✅.
4. **Bg preto puro #000** — diferente do nosso Vanta `#0A0A0A`. Para LPs SINAPSE, manter `#0A0A0A` (mais sofisticado). Mas no theme dark do brandbook, podemos oferecer variant black puro.
5. **Geistmono como mono primary** — explicitamente Geistmono (não JetBrains). Considerar Geist Mono variável como upgrade.
6. **Página single-section épica (31K scroll)** — manter a narrativa em uma só página long-scroll para LPs comerciais SINAPSE.
